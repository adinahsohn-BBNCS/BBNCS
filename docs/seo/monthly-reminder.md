# BBNCS monthly SEO reminder

Run on the **first week of each month** (~15–20 minutes).

## Google Business Profile

Log in: [business.google.com](https://business.google.com)

- [ ] Check **Insights** — calls, direction requests, website clicks
- [ ] Post **1 update** (consultation offer, IT tip, seasonal note)
- [ ] Add or refresh **photos** if none this month
- [ ] Verify **hours**, **services**, and **website** (`https://bbncs.com`) match the site
- [ ] **Reply to new reviews** (within 48 hours)
- [ ] Send **2–4 review requests** to happy clients → share [bbncs.com/review/](https://bbncs.com/review/)

Full checklist: `docs/seo/gbp-checklist.md`

## Bing Places (manual sync)

Bing does **not** auto-update from Google.

1. Open [bingplaces.com](https://www.bingplaces.com)
2. Click **Sync with Google**
3. After 24–72 hours, spot-check Bing Maps: `Bits Bytes Nibbles Temecula`

Full steps: `docs/seo/bing-places-checklist.md`
